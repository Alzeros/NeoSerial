# NeoSerial

本机自用的串口调试工具，面向通信模组嵌入式开发。经典工程软件风格（参考 SSCOM/XCOM）。Rust + Slint + serialport。

## 构建

```bash
cargo run            # debug 运行
cargo run --release  # release 运行
```

## 界面布局

三层 + 状态栏，信息密度高、一屏完成常用操作：

```
┌──────────────────────────────────────────────────┐
│ 顶部：串口配置（COM/Baud/数据位/校验/停止位/流控）│
├────────────────────────────┬─────────────────────┤
│ 左：日志区（白底，70%）     │ 右：命令脚本侧边栏  │
│                            │   （Tab + 命令列表） │
├────────────────────────────┴─────────────────────┤
│ 底部：快捷发送（输入框 + 行尾互斥组 + HEX + 发送）│
├──────────────────────────────────────────────────┤
│ 状态栏：连接状态 / COM / Baud / TX / RX 字节     │
└──────────────────────────────────────────────────┘
```

## 使用

1. 顶部配置串口参数（数据位/校验/停止位/流控可选），点 Connect。
2. 底部输入框输入 AT 命令，回车发送；行尾用互斥按钮组选 CR/LF/CRLF/无，HEX 开关切十六进制发送。
3. 日志区白底显示收发，每行格式 `[时间戳] [发送/接收] 内容`：
   - 工具栏「时间」开关：控制屏幕 + 存盘是否带时间戳。
   - 工具栏「记发送」开关：开则发送指令进日志/存盘（带 `[发送]` tag），关则不记录；接收始终带 `[接收]` tag。
   - TX 深绿 / RX 近黑 / ERROR 红（白底可辨）。
4. 工具栏：ASCII/HEX、时间、记发送、暂停、清屏、存盘、自动滚动。
   - 存盘：点「开始存盘」弹「另存为」选位置（默认 `neoserial_YYYYMMDD_HHMMSS.log`）；存盘中可点「📂 所在文件夹」在资源管理器定位文件，或「⏹ 停止存盘」。
5. 右侧命令脚本侧边栏：点命令即发送；「+」新增、✎ 编辑（载入输入框）、✕ 删除。从配置加载，增删改即存。
6. 配置自动保存到 `%APPDATA%\neoserial\settings.json`。

## 架构

连接为中心：每个 Connection 是自包含单元（串口句柄 + 环形缓冲 + 读线程），UI 是它的视图。
- UI 线程：Slint 事件循环 + 20ms Timer 刷新。
- 读线程：阻塞 read + 行累加，按行推入环形缓冲；发送命令在此线程同步写串口。**存盘由读线程驱动**——切出完整行后按显示开关生成 `[ts] [tag] content` 文本行，经非阻塞 channel 甩给存盘线程写文件（独立于 UI Timer，暂停屏幕时存盘照写，只存完整行）。
- 存盘线程：按需 spawn，写格式化文本日志。
- 显示开关（时间戳/记录发送）经 `SetDisplay` 命令动态下发读线程，即时生效。

详见 `docs/superpowers/specs/2026-07-15-ui-rework-design.md`。

## 手动验证清单

逐项手动验证。需要真实串口设备或虚拟串口工具：

1. [ ] 顶部配置数据位/校验/停止位/流控 → Connect → 发 `AT` → 收 `OK`，时间戳与 `[发送]`/`[接收]` tag、着色正确。
2. [ ] 工具栏「时间」开关：开→屏幕+存盘带时间戳；关→都不带，屏幕立即重渲染。
3. [ ] 工具栏「记发送」开关：关→发送指令不在屏幕显示、不进存盘；接收照常显示。
4. [ ] 高频 log（虚拟串口灌数据）→ UI 不卡、滚动流畅；状态栏 TX/RX 字节实时累加。
5. [ ] 开始存盘（弹「另存为」选 .log）→ 灌数据 → 停止存盘 → 文件每行 `[ts] [tag] content` 完整；点「📂 所在文件夹」能定位文件。
6. [ ] 运行中拔 USB → 状态切 Disconnected，app 不崩，历史可看。
7. [ ] 暂停 → 屏幕冻结，恢复后能看到暂停期间进缓冲的新行（存盘不受暂停影响）。
8. [ ] ASCII↔HEX 切换瞬间生效、内容正确。
9. [ ] 右侧侧边栏：点命令发送、+ 新增、✕ 删除（关闭重开后保留）、✎ 编辑载入输入框。
10. [ ] 关闭重开 → 串口参数、命令脚本、显示开关、窗口尺寸恢复。

## 已知 v2 优化点（不在本轮范围）

- 命令队列执行引擎：点 Run 按顺序自动发一串（含执行顺序/延迟/重试/超时/等待回复）。
- 多 Tab 命令组管理（本轮单 Tab，模型预留）。
- 可拖拽分隔条（本轮固定 70/30）。
- 日志搜索/过滤/正则/高亮/收藏。
- 自动滚动检测：手动上滚自动关闭，滚回底部自动重开（本轮靠手动切换）。
- 发送历史 cursor 完整导航（本轮上=最后一条/下=清空）。
- 多串口标签页、多设备管理。
- HEX 十六进制网格双面板。
- 原始字节捕获（被格式化存盘取代，未来可作独立开关）。
- u64→i32 字节统计限幅（长时间挂机超 2GB 会回绕）。
