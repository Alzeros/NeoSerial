# NeoSerial

本机自用的串口调试工具，面向通信模组嵌入式开发。经典工程软件风格（参考 SSCOM/XCOM）。Tauri 2 + Svelte 5 + Rust + serialport。

## 构建

```bash
npm install          # 安装前端依赖
npm run tauri dev    # 开发模式（同时启动 Vite + Cargo）
npm run tauri build  # 发布构建（生成安装包）
```

## 技术栈

- **前端**: Svelte 5 + TypeScript + Tailwind CSS + Vite
- **后端**: Rust + Tauri 2 + serialport
- **通信**: Tauri IPC（invoke / listen）+ 批量 Event 推送

## 界面布局

三层 + 状态栏，信息密度高、一屏完成常用操作：

```
┌──────────────────────────────────────────────────┐
│ 顶部：串口配置（端口/波特率/数据位/校验/停止位/流控）│
├──────────────────────────────────────────────────┤
│                                                  │
│                   数据显示区                      │
│                                                  │
├──────────────────────────────────────────────────┤
│ 底部：操作按钮 + 复选框 + 发送输入 + 文件/日志    │
├──────────────────────────────────────────────────┤
│ 状态栏：连接状态 / Tx / Rx                        │
└──────────────────────────────────────────────────┘
         右侧：命令脚本侧边栏（可折叠）
```

## 架构

连接为中心：每个 Connection 是自包含单元（串口句柄 + 环形缓冲 + 读线程），UI 是它的视图。

- **前端**: Svelte 5 $state 响应式 store + Tauri invoke/listen 通信
- **读线程**: 阻塞 read + 行累加，按行推入环形缓冲 + 批量 emit Tauri Event（16行/5ms）
- **写线程**: 通过 crossbeam channel 接收写命令，独立于读线程
- **配置**: 自动保存到 `%APPDATA%\neoserial\settings.json`

## 功能

- 串口参数配置（端口/波特率/数据位/校验/停止位/流控）
- 手动发送（支持 HEX/ASCII、行尾选择、回车发送）
- 文件发送（分块读取 + 实时进度）
- 日志记录（可选记录发送内容）
- 命令脚本序列（多页签、可保存/加载配置）
- 显示选项（HEX显示、时间戳、自动滚动）
- 连接模式自动降级（独立句柄 → 共享端口）
